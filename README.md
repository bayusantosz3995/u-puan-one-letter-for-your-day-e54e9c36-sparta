One letter, A to Z, standing for the word that describes my day.

The letter is **G** — for **glitch**: a day spent battling digital
hiccups, everything flickering and going wrong. The crisp visual flicker
of a glitch calls up a sharp picture of the day at once, and the hard
"g" start fits the jagged shape of the letter G itself.

Run `python3 main.py` — it writes the single letter to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), after gating
on exactly one character, a letter A–Z, and verifying the write
byte-for-byte.
